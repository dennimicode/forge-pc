# FORGE — учебная мастерская ПК

Сайт на **Vue 3 + Vite**, полностью статический и готовый для **GitHub Pages**. Пять отдельных страниц, каталог с фильтрами, конфигуратор, учебная форма заказа и интеграции LiveInternet / Рамблер/Топ-100 / Рейтинг Mail.ru. Go, SMTP, сервер, база данных и приватные токены не нужны.

## Как работает заказ

1. Выберите сборку, RAM, SSD и цвет: сумма пересчитывается сразу.
2. Введите тестовые контакты и подтвердите локальное сохранение.
3. Нажмите **«Создать учебную заявку»**: появятся номер, дата, комплектация и сумма.
4. Скачайте **TXT или JSON**, скопируйте текст либо удалите заявку.

Последняя заявка хранится в `localStorage` текущего браузера, восстанавливается после перезагрузки и заменяется новой. При запрещённом хранилище доступно скачивание до закрытия страницы; интерфейс сообщает об этом. Черновики контактов не сохраняются.

**Владелец сайта не получает заявку.** Это учебная имитация оформления заказа без оплаты. GitHub Pages публикует статические файлы и не принимает заказы на сервере. Общая база и автоматическая доставка владельцу требуют внешнего сервиса, который для этого проекта не используется. Счётчики работают напрямую с сервисами аналитики после регистрации и согласия посетителя.

## Публикация без установки программ

Распакуйте **`forge-pc-pages.zip`**, загрузите его содержимое в корень публичного репозитория GitHub. Выберите **Settings → Pages → Deploy from a branch → main / root**. После публикации адрес будет указан там же. Настройки счётчиков редактируйте в `site-config.js` в корне репозитория. `assets/`, `fonts/` и пять HTML должны лежать рядом.

## Разработка и автоматическая сборка

Нужен Node.js 22.12+.

```sh
npm ci
npm run dev
```

Проверки: `npm test`, сборка: `npm run build`. Результат — `dist/`. Каталог и цены находятся в `src/data/catalog.json`.

Для GitHub Actions загрузите **содержимое папки исходников**, включая `.github/`, в корень ветки `main`, без `node_modules/`. В Pages выберите Source: **GitHub Actions**. Workflow проверит и соберёт Vue, затем опубликует `dist/`. Не смешивайте этот способ с загрузкой готовой сборки.

Используется `base: './'`: ресурсы и переходы поддерживают адрес `https://username.github.io/repository/`. Каждая страница открывается напрямую, без SPA-редиректов.

## Аналитика

Места, требующие ваших действий, отмечены `USER_ACTION` в `public/site-config.js`. Только публичные ID и адреса — никаких секретов. Две цели: `config_selected` — переход к оформлению, `order_created` — создание учебной заявки в браузере. Они не означают покупку или доставку заказа.
