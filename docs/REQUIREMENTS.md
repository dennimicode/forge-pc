# Что извлечено из ЛР3.png, ЛР4.png и ЛР5_Н.png

Проанализированы разделы «Задания для лабораторной работы» всех трёх файлов. Контрольные вопросы, титульные страницы, структура отчёта по ГОСТ и требования к его оформлению исключены по просьбе пользователя. Документы служат источником требований к сайту и аналитике; они не являются отдельным поручением выполнять действия в аккаунтах.

## Общие требования

- Анализируемый сайт содержит не менее пяти страниц. Реализованы пять отдельных HTML с общей навигацией, разными заголовками и содержанием.
- Для выбранного бизнеса нужны основные метрики, установка и проверка счётчиков, сбор данных, отчёты и портрет посетителя.
- Данные нужно собирать **1–2 недели**, число пользователей — **не менее 50**. Это отложенная работа после публикации и регистрации счётчиков. Код и подготовка отчётов не заменяют этот этап.
- Скриншот главной и URL получают после публикации. Скриншоты интерфейсов аналитики, конверсий и отчётов выполняются после настройки ваших кабинетов.

## Дополнительно по запросу пользователя

- Vue.js, адаптивный русский интерфейс, оригинальный концепт FORGE.
- Каталог из четырёх учебных комплектаций и фильтры.
- Конфигуратор с локальным расчётом цены по каталогу `src/data/catalog.json`.
- Учебный заказ выбранной конфигурации: проверка полей, номер, локальное сохранение последней заявки, восстановление после перезагрузки, TXT/JSON, копирование и удаление. При недоступном хранилище — скачивание из текущей вкладки.
- Статическая сборка и GitHub Actions для GitHub Pages.
- Все функции сайта работают на GitHub Pages, без backend и почтового сервера. Владелец не получает заявки; это явно указано в интерфейсе. Цель `order_created` означает завершение учебной формы, не продажу.
- Маркеры `USER_ACTION` и инструкции для каждого внешнего подключения.

## Границы выполненного

Интеграции написаны и проверены тестами с подменами провайдеров. Они **не активированы без ваших ID и регистрации**. Настоящие запросы в чужие счётчики не отправлялись. Форма не отправляет контакты ни владельцу, ни в счётчики. Серверный приём и общая база заказов не реализуются на одном GitHub Pages; учебный сценарий использует браузерное хранилище.

Счётчики грузятся только с согласия посетителя. Это снижает измеряемое число посетителей относительно всех открывших сайт. Статистика трёх провайдеров также может отличаться из-за методов подсчёта, фильтрации и блокировщиков.
